# GE Smart Timer & Error Control

Extension Chrome pour assister sur les exercices GlobalExam (QCM et champs à remplir) via l'API Gemini.

## Installation

1. Télécharge le dépôt en ZIP (**Code -> Download ZIP**) et extrais le dossier.
2. Ouvre `chrome://extensions` dans Google Chrome.
3. Active le **Mode développeur** en haut à droite.
4. Clique sur **Charger l'extension non empaquetée** et sélectionne le dossier extrait.

## Configuration de la clé API

1. Crée une clé API sur [Google AI Studio](https://aistudio.google.com/apikey).
2. Ouvre `chrome://extensions`, clique sur **service worker** sous l'extension, puis enregistre ta clé dans la console :
3. Recharge la page GlobalExam (`Cmd + R` ou `Ctrl + R`) et active l'extension.
